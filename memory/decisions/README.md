# Decision log

Durable record of meaningful decisions so the team (and future agents) stay consistent. One file per
decision: `YYYY-MM-DD-<slug>.md`. The Chief of Staff appends here when the CEO makes a call worth
remembering (positioning, pricing stance, who to prioritize, process changes).

```markdown
---
date: 2026-09-10
decision: "Prioritize warehouse-manipulation ICP for first design partners."
decided_by: CEO
context: <why>
---
Details, alternatives considered, and any follow-up actions.
```
